# AI Value & Cost — Daily Digest

Automated daily scan of working-paper feeds (NBER, arXiv econ.GN), management research, analyst newsrooms and data-centre/energy sources, filtered for the economics of AI: ROI, TCO, productivity evidence, adoption failure rates and the indirect-cost categories tracked by ValorAI. Items are unreviewed links — verify against the primary source before relying on them.

Updated automatically every day by the **Daily AI Value Digest** GitHub Actions workflow.
Roughly 90 days of history are kept on this page; the latest run is also written to
`data/digest-latest.json`.
